## Objetivo

Criar um **app React** (Vite + TypeScript) com um **to-do de tasks** usando
apenas o que vimos na aula: **componentes, parâmetros (props), callbacks e
estado (`useState`)**. Tudo local, sem API.

A entrega segue o **fluxo Git do curso**: uma branch própria, um diretório com
o mesmo nome dela e, dentro dele, o app e um `tf.md` com os seus dados. A
entrega é um **Pull Request** do seu fork para o `main` do professor.

## O que NÃO pode usar

Só vimos **estado**. Referências e efeitos ficam para a próxima aula, então
**não use**:

- ❌ `useEffect`
- ❌ `useRef`
- ❌ bibliotecas de estado, de formulário ou de UI além do que o Vite gera

## O que o app precisa fazer

Uma lista de tasks, no contexto que já conhecemos (`Task`: `id`, `name`,
`isDone`):

1. **Adicionar** uma task digitando o nome num campo (campo controlado) e
   clicando em "Adicionar". Nome vazio não adiciona.
2. **Marcar/desmarcar** a task como feita ao clicar nela.
3. **Excluir** uma task.
4. **Filtrar** a lista por **Todas / Pendentes / Feitas**. O filtro é um
   estado com tipo união: `type Filter = "all" | "pending" | "done"`.
5. Mostrar o contador **"N pendente(s)"**, calculado a partir da lista
   (valor derivado, sem criar outro estado).
6. Mostrar "Nenhuma task" quando a lista (filtrada) estiver vazia.

## Regras de código

- ✅ Componentes separados, no mínimo: `TaskForm`, `TaskList` e `TaskItem`
  (o `App` é o dono do estado e passa dados por props e funções por callback)
- ✅ Tipar tudo em TypeScript (`strict`), sem `any`; `type Props` em cada
  componente; generics explícitos quando o valor inicial não basta
  (`useState<Task[]>([])`)
- ✅ Arquivos de componente em **`.tsx`**
- ✅ Só `const`: nunca `let` em componente
- ✅ Estado booleano com prefixo `is`: `const [isDone, setIsDone] = ...`
- ✅ Imutabilidade: nunca alterar array ou objeto do estado no lugar
  (use `[...lista, nova]`, `map` e `filter`)
- ✅ Quando o novo estado depende do anterior, use a **forma de função**
  (`setTasks(current => ...)`)
- ✅ Evento de clique explícito: função nomeada ligada no JSX
  (`onClick={handleAdd}`)
- ✅ Sem `else` / `else if` (early return ou valor padrão antes do `if`)
- ✅ `key` estável nas listas (o `id`, nunca o índice)

## Como entregar

A branch **tem que se chamar `RA-tf-08`**: o seu RA, `-tf-` e o número do TF
com 2 dígitos. Exemplo para o RA `1234567`: `1234567-tf-08`.

**Sem a branch com esse nome, o TF vale ZERO.**

1. Fazer o **fork** do repositório do professor e clonar o **seu fork**
   (veja a documentação "Fluxo Git do aluno").
2. Atualizar o `main` e criar a branch do TF a partir dele:

```sh
git switch main
git pull --ff-only upstream main
git switch -c 1234567-tf-08
```

3. Criar, na **raiz do repositório**, um diretório com **exatamente o mesmo
   nome da branch**, com o app React e o `tf.md` dentro:

```text
1234567-tf-08/
├── tf.md
└── app/            ← o projeto React (npm create vite@latest app -- --template react-ts)
```

```sh
mkdir 1234567-tf-08
cd 1234567-tf-08
npm create vite@latest app -- --template react-ts
```

4. Criar o `tf.md` dentro do diretório, com o seu **nome**, o seu **RA** e o
   seu **GitHub** (link do seu perfil, por extenso):

```text
Nome: Maria da Silva
RA: 1234567
GitHub: https://github.com/maria-silva
```

5. Commitar e enviar para o **seu fork**. Não commite a pasta
   `node_modules` (o `.gitignore` do Vite já cuida disso):

```sh
git add -A
git commit -m "TF-08"
git push -u origin 1234567-tf-08
```

6. Abrir o **Pull Request** da sua branch para o `main` do professor
   (`luan-tavares/unifaat-2026-frontend`):

```text
https://github.com/luan-tavares/unifaat-2026-frontend/compare/main...SEU-USUARIO:1234567-tf-08?expand=1
```

   - **Título do PR:** `TF-08 · RA · Nome` (ex.: `TF-08 · 1234567 · Maria da Silva`)
   - **Descrição:** o conteúdo do seu `tf.md`

O PR nunca será mergeado: o professor o fecha depois de corrigir.

7. Preencher o **formulário de entrega** com Nome, RA e Repositório Git
   (link do seu fork ou do seu Pull Request):

🔗 https://docs.google.com/forms/d/e/1FAIpQLSfQWln5GAxiFlYf2IVEKINvJ5qEjfVWgMJNAyalcBqFRUqOJw/viewform?usp=publish-editor

## Como conferir antes de entregar

- A branch no GitHub se chama `RA-tf-08` (com o **seu** RA)
- Na raiz existe o diretório com o mesmo nome da branch
- Dentro dele: `tf.md` (Nome, RA e GitHub) e a pasta `app/`
- `cd app && npm install && npm run dev` abre o to-do funcionando
- `npx tsc --noEmit` (dentro de `app/`) sem erro
- Nenhum `useEffect` nem `useRef` no código
